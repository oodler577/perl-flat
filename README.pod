Suite of Regular Language modelling tools that were
originally created as part of a homework assignment.
back in 2006.

Development roadmap and design notes are in docs/ROADMAP.md and
docs/DESIGN.md. Build instructions are in docs/DEVELOPMENT.md.
Known baseline defects and the research plan are recorded in
docs/KNOWN_GAPS.md and docs/RESEARCH.md.

The installed fash command is documented in docs/CLI.md, including JFLAP
finite-automaton import/export, token input and command exit statuses.

Installed manuals: perldoc perlflat (library overview) and perldoc perlfash
(CLI guide and workbench proposals). Bash completion is installed by make
install; use fash completion bash to generate it for the current shell.
